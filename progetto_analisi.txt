========================================
STRUTTURA PROGETTO ASSISTENTE AI UNIFICATO
========================================

Questo documento descrive la struttura completa del progetto "agente_ai"
un sistema multi-agente per chat con Ollama, creato unendo due progetti:
- Multi_agentico: sistema di agenti con Ollama
- Simplify_F1nANCyA_ItALiAn: assistente finanziario italiano

========================================
DESCRIZIONE FILE E OTTIMIZZAZIONI
========================================

=== BACKEND ===

1. **backend/wsgi_main.py** (Server principale)
   DESCRIZIONE: Server WSGI principale che gestisce tutte le richieste HTTP.
   Gestisce routing, CORS, logging e avvia il server su porta 54324.
   Funzionalità: API endpoints per chat, agenti, modelli, grafici 3D, news.

   OTTIMIZZAZIONI:
   - Rimuovi endpoint non utilizzati (es. alcuni endpoint grafici se non necessari)
   - Implementa caching per risposte ripetute
   - Riduci logging verboso in produzione
   - Aggiungi rate limiting per sicurezza

2. **backend/server_utils.py** (Utilità server)
   DESCRIZIONE: Funzioni di utilità per validazione API key, gestione modelli,
   generazione grafici, analisi codice, esecuzione Python sicura, sintesi vocale.

   OTTIMIZZAZIONI:
   - Rimuovi funzioni non utilizzate (es. alcune funzioni di analisi codice duplicate)
   - Ottimizza generazione grafici (usa cache per evitare rigenerazioni)
   - Migliora sicurezza esecuzione codice (sandbox più robusto)
   - Unifica gestione errori

3. **backend/agent_integration.py** (Integrazione agenti)
   DESCRIZIONE: Gestisce la creazione e comunicazione con agenti MCP.
   Fornisce endpoint per creare agenti, chattare con agenti specifici.

   OTTIMIZZAZIONI:
   - Unifica con server_utils.py per ridurre duplicazioni
   - Aggiungi gestione sessioni agenti più efficiente
   - Implementa cleanup automatico agenti inattivi

=== AGENT MODULE ===

4. **backend/agent/mcp_agent.py** (Agente principale)
   DESCRIZIONE: Classe principale MCPAgent che orchestra modelli, memoria, task.
   Gestisce selezione automatica modelli basata su modalità, memoria conversazioni.

   OTTIMIZZAZIONI:
   - Rimuovi modalità non utilizzate
   - Ottimizza selezione modelli (cache risultati)
   - Riduci complessità memoria (usa database invece di memoria RAM)
   - Migliora gestione errori

5. **backend/agent/ollama_interface.py** (Interfaccia Ollama)
   DESCRIZIONE: Interfaccia per comunicazione con Ollama usando libreria ufficiale.
   Gestisce generazione risposte, lista modelli, streaming.

   OTTIMIZZAZIONI:
   - Rimuovi dipendenze requests (usa solo ollama library)
   - Aggiungi retry logic per connessioni fallite
   - Implementa connection pooling
   - Riduci logging dettagliato

6. **backend/agent/memory_manager.py** (Gestione memoria)
   DESCRIZIONE: Gestisce memoria conversazioni e contesto per agenti.

   OTTIMIZZAZIONI:
   - Implementa persistenza su disco/database
   - Aggiungi limiti memoria per evitare OOM
   - Ottimizza ricerca in memoria
   - Implementa cleanup automatico

7. **backend/agent/task_manager.py** (Gestione task)
   DESCRIZIONE: Gestisce task asincroni e multi-threading.

   OTTIMIZZAZIONI:
   - Semplifica gestione thread (usa async/await)
   - Aggiungi timeout task
   - Migliora error handling
   - Riduci complessità

8. **backend/agent/specialized_modules.py** (Moduli specializzati)
   DESCRIZIONE: Moduli per compiti specifici (matematica, codice, psicologia, finanza).

   OTTIMIZZAZIONI:
   - Rimuovi moduli non utilizzati
   - Ottimizza prompt (meno verbosi)
   - Unifica logica comune
   - Aggiungi caching risultati

9. **backend/agent/model_mapping.py** (Mappatura modelli)
   DESCRIZIONE: Mappa task a modelli ottimali.

   OTTIMIZZAZIONI:
   - Semplifica logica mapping
   - Aggiungi apprendimento automatico per scelte migliori
   - Riduci hardcoded, usa configurazione
